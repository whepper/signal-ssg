# ADR 0023: Route-to-URL path encoding

## Status

Accepted (slice 15C; remediation of the fresh-review finding R14-3).
Extended in slice 15E: front-matter image `src` and internal menu URLs use
the same boundary.

## Context

Logical routes may contain URL-significant characters (`issue#12`,
`100%-done`, `a?x=1`), but every URL-producing subsystem concatenated the
raw route onto the base URL. The same unencoded route propagated into
listing links, canonical URLs, OpenGraph metadata, JSON-LD, RSS links and
GUIDs, sitemap locations, and search-index paths — so `#` became a fragment
delimiter, `?` a query introducer, and `%` an invalid escape, and the
published URLs did not address the generated artifacts.

## Decision

- **One boundary.** `signal_core::encode_route_path(&Route) -> String` is
  the single route-to-URL serialization point, used directly or via
  `canonical_url` by every URL producer: entry/section/home/taxonomy
  canonical + OpenGraph + JSON-LD contexts, `EntrySummary.route` (listing
  links), `TopicRow.route`, search `id`/`url`, feed item links/GUIDs and
  channel links, sitemap locations, and feed `self` links (via the sibling
  `encode_url_path` for artifact output paths, which are not routes).
- **Conservative segment policy.** The route splits on `/` (separators stay
  structural, trailing slashes preserved) and each segment encodes
  independently: RFC 3986 unreserved bytes (`A-Z a-z 0-9 - . _ ~`) stay
  literal; every other byte — `%`, `?`, `#`, sub-delims, `:`/`@`, UTF-8
  bytes — becomes uppercase-hex `%XX`. A route path is opaque site data, so
  no delimiter semantics may leak.
- **Routes are literal data.** A literal `%` is always encoded
  (`100%25` → `100%2525`); no `%xx`-looking input is ever misread as an
  escape, and decoding inverts exactly. Unicode encodes as UTF-8 with no
  normalization. The base URL is concatenated, never encoded.
- **Layers stay distinct.** URL-path encoding precedes HTML-attribute, JSON,
  and XML escaping; it replaces none of them. Bare `route` values keep the
  logical form only where typed as [`Route`] (menu matching, model lookups,
  manifest keys, filesystem paths); every route-shaped *string* handed to a
  template or serializer is the encoded URL path.
- **What did not change.** Route identity, slug validation, filesystem
  output paths (`posts/issue#12/index.html` on disk), menu URL validation
  semantics (authored URLs, validated as before; only the emitted internal
  `href` is encoded as of 15E), and semantic input digests (entry digests
  still hash the raw route).

## Consequences

- `/posts/issue#12/` serializes to `/posts/issue%2312/` everywhere;
  `/posts/a?x=1/` to `/posts/a%3Fx%3D1/`; `café` to `caf%C3%A9`.
- Ordinary slugs render byte-identically to before; only routes with
  URL-significant or non-ASCII characters change bytes.

## Follow-up (slice 15E)

Two producers missed in 15C now use the same boundary:

- **Front-matter image `src`.** The `image` template value carried the raw
  resolved site-root path while `og:image`/JSON-LD (via `absolute_url` →
  `canonical_url`) carried the encoded form, so one image had two URLs.
  The context value is now encoded with `encode_url_path` at insertion.
  Absolute (`http(s)://…`) and protocol-relative (`//…`) values pass
  through untouched — encoding them would destroy the scheme. Markdown
  image/link destinations are intentionally unchanged: they are authored
  URLs where queries (`?v=2`) and fragments (`#heading`) are legitimate.
- **Internal menu URLs.** `MenuItem.url` for internal items is now the
  URL-path-encoded form (`/posts/100%-done/` →
  `/posts/100%25-done/`), matching generated route links. Active matching
  still compares raw logical routes, and external URLs pass through
  untouched. Authored values are literal data: an authored `%` encodes
  rather than acting as an escape.

## Reuse

Encoding changes generated bytes without changing recorded semantic
inputs, so `GENERATION_BEHAVIOR_VERSION` was bumped `1` → `2` in 15C and
`2` → `3` in 15E per ADR 0019 — no new `InputRef`, no digest changes. The
frozen sample manifest golden was refreshed for the version field only;
public output is byte-identical (all fixture routes, images, and menu URLs
are unreserved, so encoding is the identity there).

## Out of scope (unchanged)

Source symlink policy (R14-4), YAML parser (R14-6), route normalization,
filesystem naming, template closure, generation architecture, pruning.
(Manifest trust wording, listed here in 15C, was qualified in 15E — see
ADR 0017.)
